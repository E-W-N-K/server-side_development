# Современные технологии серверной разработки

Лабораторные работы Сакун Е.А. Каждая работа находится в отдельной ветке:

- `lr1` — Git;
- `lr2` — JDBC;
- `lr3` — Marshalling.

Переключение: `git switch lr1`, `git switch lr2` или `git switch lr3`.
В каждой ветке находится самостоятельное Java-приложение, инструкция по запуску и отчёт `report.docx`.
