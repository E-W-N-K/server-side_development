# Лабораторная работа №2 — JDBC

Сакун Е.А. Учебное консольное приложение на Java 21.

Программа создаёт в памяти H2 таблицы `authors`, `books`, `shops`, `shops_books`, `students`, `courses`, `suppliers`, заполняет исходные данные и выполняет все запросы блока `Statement`. Для двух дополнительных сущностей (`courses`, `suppliers`, по четыре поля) через `PreparedStatement` выполняются вставка, изменение и поиск по идентификатору. Эти операции объединены транзакцией.

Запуск: `mvn compile exec:java`. СУБД отдельно устанавливать не нужно; база создаётся заново при каждом запуске. Требуются JDK 21 и Maven.

Файл `report.docx` содержит отчёт по образцу лабораторной №1.
